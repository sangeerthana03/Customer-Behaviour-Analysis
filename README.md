# Customer Behaviour Analysis

An exploratory data analysis project focused on understanding customer purchasing patterns, spending behaviour, product performance, customer segments, subscriptions, discounts, and purchasing frequency.

## Project Overview

This project analyzes customer shopping data to identify meaningful patterns in purchasing behaviour and answer business-related questions using Python and SQL.

The analysis covers data cleaning, exploratory data analysis, feature creation, customer segmentation, revenue analysis, and SQL-based business queries.

## Objectives

* Understand customer purchasing behaviour
* Analyze spending patterns across different customer groups
* Identify popular products and product categories
* Compare purchasing behaviour across gender and age groups
* Analyze subscription and discount usage
* Examine customer purchase frequency
* Answer business-related questions using SQL

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/sangeerthana03/Customer-Behaviour-Analysis.git
```

### 2. Navigate to the project folder

```bash
cd Customer-Behaviour-Analysis
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Open the Jupyter Notebook

```bash
jupyter notebook
```

Open `Customer_Behaviour_Analysis.ipynb` and run the notebook.
